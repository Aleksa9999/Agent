# 10: Запуск навыка: таски, смета и пакет промптов

**Статус:** todo

**Блокируется:** 09 (Запуск навыка: допрос и спека)

**Закрывает критерии:** К11

## Что построить

Агент режет спеку на вертикальные срезы с блокировками и картой покрытия критериев, показывает смету коробки по трём уровням с ценами из каталога моделей и отдаёт пакет промптов и правил для самостоятельной работы. Для навыков с кодом на этом этап концепции заканчивается: код не пишется.

## Критерии приёмки

- [ ] При запуске навыка агент проходит фазы допроса, спеки, нарезки на таски и пакета промптов: на выходе есть спека с критериями К, таски с картой покрытия, смета трёх уровней коробки с ценами из каталога моделей и пакет промптов для самостоятельной работы.
- [ ] Критерий, не закрытый ни одним срезом, показан отдельно с вопросом «осознанно ли».
- [ ] Цены в смете берутся из каталога моделей, не из памяти.
- [ ] Для навыка с кодом агент не пишет и не запускает код проекта человека.
