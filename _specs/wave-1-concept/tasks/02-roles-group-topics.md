# 02: Роли, группа, темы и команды владельца

## Что построить

Новый участник тестовой группы получает тему со своим именем и кнопку «Начать с моим агентом». По кнопке открывается личка с темами «Профиль», «Навыки», «Проект», «Отчёты»; если клиент не поддерживает темы, работает `/project`. Роли определяются по Telegram-ID из серверного реестра. Команды владельца видны и доступны только ему. Повторные нажатия и старые кнопки не создают дублей.

## Критерии приёмки

- [ ] Новый участник тестовой группы получает тему со своим именем и кнопку «Начать с моим агентом»; по ней открывается личка с темами «Профиль», «Навыки», «Проект», «Отчёты» (или работает `/project`) меньше чем за 5 секунд.
- [ ] Команды владельца доступны только Telegram-ID владельца из серверного реестра; другой пользователь не видит их в меню и получает отказ при вводе.
- [ ] Повторное вступление и повторное нажатие кнопки не создают вторую тему.
- [ ] Старая кнопка из прошлой сессии даёт понятное сообщение, а не ошибку.
