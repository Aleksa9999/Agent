# 09: Запуск навыка: допрос и спека

**Статус:** done

**Блокируется:** 04 (Оркестратор агента: наставник, исследование, расчёты), 05 (Библиотека навыков, каталог и /skill_upload)

**Закрывает критерии:** нет (подготовка к К11; закрывается срезом 10)

## Что построить

Человек выбирает навык, агент объясняет дорогу и показывает смету трёх уровней. Затем ведёт допрос по правилам навыка (пачки не больше пяти, у каждого рекомендация, «решай сам» принимается как ответ) и записывает спеку с критериями приёмки, согласованную с человеком до записи.

## Критерии приёмки

- [x] Допрос идёт пачками не больше пяти вопросов, у каждого есть рекомендация и кнопки стандарта А.
- [x] Ответ «решай сам» принимается, решение записывается в журнал «что решил агент за вас» и не переспрашивается.
- [x] Спека содержит критерии К1…Кn, сформулированные от наблюдаемого поведения, и раздел «Вне рамок».
- [x] Спека показывается человеку и записывается только после его согласия.
- [x] Для задач на актуальные данные агент использует исследование со ссылкой и датой.
