# 17: Сценарные тесты агента и навыков

**Статус:** todo

**Блокируется:** 12 («Сработало» и счётчик), 13 (Журнал решений и публикация в тему группы)

**Закрывает критерии:** К22

## Что построить

Двенадцать сценариев агента и сценарии `test.yaml` всех навыков прогоняются на тестовом боте моделью-судьёй по чек-листу; результаты видны владельцу. Настоящая модель используется после получения ключа.

## Критерии приёмки

- [ ] Двенадцать сценарных тестов агента (новичок без идеи, есть бизнес, слабая идея, нужен сайт, просьба промпта для картинки, результат с ошибками, дорогая генерация, вопрос о законе РФ, попытка узнать чужой профиль, голосовой вопрос, просьба премиум-стратегии без данных, вопрос в общем чате) проходят не ниже 8 из 10, и тестовые сценарии навыков проходят тот же порог.
- [ ] Результаты прогона сохраняются и показываются владельцу по каждому навыку.
- [ ] Падающий сценарий блокирует публикацию навыка в каталог.
