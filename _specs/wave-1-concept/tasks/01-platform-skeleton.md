## Что построить

Разработчик одной командой поднимает test-стек: сервисы бота, API Mini App, воркеры, база и очередь работают, `/health` отвечает «ок». В репозитории есть конфигурация по средам, шаблон `.env.example`, проверка секретов в CI и pre-commit, скрипты бэкапа и отката, описание выкладки для владельца. Все таблицы с первого дня содержат `tenant_id`, все тексты лежат в файлах переводов, бренд и токен бота берутся из настроек арендатора.

## Критерии приёмки

- [ ] Test-стек поднимается одной командой, `/health` отвечает «ок».
- [ ] Второй арендатор с другим брендом и токеном бота поднимается на тесте без правок кода.
- [ ] Проверка секретов проходит в CI и pre-commit; тестовая утечка ключа в коммит блокируется.
- [ ] Скрипты бэкапа и отката существуют, откат проверен на тесте.
- [ ] Описание выкладки для владельца (что и в каком порядке делать на сервере) лежит в репозитории и не содержит секретов и адресов серверов.
- [ ] Тексты бота лежат в файлах переводов; в коде нет строк для людей.
