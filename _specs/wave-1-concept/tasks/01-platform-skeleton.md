## Что построить

Разработчик одной командой поднимает test-стек: сервисы бота, API Mini App, воркеры, база и очередь работают, `/health` отвечает «ок». В репозитории есть конфигурация по средам, шаблон `.env.example`, проверка секретов в CI и pre-commit, скрипты бэкапа и отката, описание выкладки для владельца. Все таблицы с первого дня содержат `tenant_id`, все тексты лежат в файлах переводов, бренд и токен бота берутся из настроек арендатора.

## Критерии приёмки

- [x] Test-стек описан Docker Compose (`make stack-up`, файлы проходят `docker compose config`) и поднимается на реальных PostgreSQL 16 и Redis 7 командой `make native-up`; `/health` отвечает «ок», при остановленном Redis отвечает 503 и называет упавшую зависимость.
- [x] Второй арендатор с другим брендом, языком и токеном бота подключается одним YAML-файлом без правок кода (тесты `test_tenants_i18n`, `test_health`).
- [x] Проверка секретов (gitleaks) стоит в pre-commit и CI; тестовая утечка токена в коммит блокируется; вся история репозитория чиста.
- [x] Скрипты бэкапа и отката существуют; бэкап проверен на реальной базе (дамп читается, ротация оставляет 3 свежих); откат проверен на тесте со скриптовыми заглушками, боевой откат отказывает без `--confirm-owner`.
- [x] Описание выкладки для владельца лежит в `deploy/README.md` и не содержит секретов, адресов серверов и доменов.
- [x] Тексты бота лежат в `locales/*.yaml`; тест не находит кириллических строк в коде приложения.
