## Мины и особенности

- `pkill -f <слово>` убивает собственную оболочку агента, если слово есть в команде: останавливать по pid-файлам.
- gitleaks срабатывает на ключеподобные строки в тестах: фальшивые ключи собирать в рантайме, не литералами.
- Docker Compose читает переменные из `--env-file .env.test` явно (в Makefile и `rollback.sh` это учтено).
- В aiogram один Router цепляется только к одному Dispatcher: роутер создаётся фабрикой на каждого арендатора.
- Заглушка модели в тестах применяет те же правила запросов, что настоящий клиент; смешивать встроенные инструменты и свои функции в одном запросе нельзя (`ToolConflictError`).
- Любой текст для людей только в `locales/*.yaml`; тест запрещает кириллицу в коде приложения. Промпты лежат в `prompts/`.
- PostgreSQL для тестов должен быть в UTF-8 (в `deploy/native-stack.sh` исправлено).
