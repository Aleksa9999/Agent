# Путь человека: от входа до зачтённого навыка

Составлен 28 октября 2026 по коду на этот день. Для каждого шага: что человек видит, где это (чат бота или Mini App) и что ему доступно. В конце: что сейчас не работает или не построено.

## Входы

| Откуда | Что происходит |
|---|---|
| Вступил в группу | Бот создаёт тему с именем человека и пишет в ней приветствие с кнопкой «Начать с моим агентом» |
| Кнопка «Начать» или `/start` в личке | Бот создаёт четыре темы («Профиль», «Навыки», «Проект», «Отчёты»), приветствует, убирает старую кнопку над клавиатурой и предлагает «Открыть» / «Не сейчас» |
| Синяя кнопка меню слева от поля ввода | Открывает Mini App (с данными входа) |
| Кнопка «Открыть» под сообщением бота | Открывает Mini App (с данными входа) |
| Любой текст в личке | Отвечает агент (настоящая модель) в той теме, где написано |
| Голосовое в личке | Распознаётся, заполняет анкету, бот присылает «Услышал и записал N из 12» и предлагает открыть Mini App |

Mini App, открытый кнопкой на клавиатуре, войти не может: Telegram не даёт ему данные входа. Эта кнопка убрана.

## Шаги человека

**1. Новый человек.** Mini App показывает «Привет, {имя}!» и карточку «Начнём с тебя» с кнопкой «Пройти тест». Остальные вкладки открыты: «Навыки» (каталог), «Профиль», «Настройки».

**2. Тест на входе** (вкладка «Профиль»). Три способа, все пишут в один профиль:
- «Рассказать голосом»: запись до 5 минут, агент заполняет анкету и спрашивает только недостающее. Кнопка видна, только если на сервере заданы ключ Qwen и модель распознавания; если микрофон недоступен, экран предлагает голосовое сообщение в чат.
- Голосовое в чате: то же, результат виден в Mini App.
- «Заполнить анкету кнопками»: блоки по 5 вопросов, у каждого четыре варианта и ⭐, кнопки «Свой ответ», «Не знаю», «Назад», «Сравнить»; прерванная анкета продолжается с того же вопроса.

**3. Карточка профиля.** 7–8 строк, кнопки «Верно» и «Поправить» (выбор строки). «Верно» создаёт паспорт v1, выбирает трек, кладёт три навыка в дерево со статусом «не проверен» и публикует публичную часть в теме группы (без денег, контактов, возраста).

**4. Главная.** Уровень 1, трек, блок «Первый результат» (для бизнеса нужно рассказать о рутине текстом или голосом; для остальных карточка идеи или план по кнопке), три навыка с кнопкой «Начать навык», 10 веток.

**5. Навык** (кнопка «Начать навык» в Mini App; дальше всё в чате бота, в теме «Навыки»):
1. Описание двух дорог и смета по трём уровням, кнопки «Делает агент» / «Пройду сам».
2. Допрос: вопросы кнопками, до 5 подряд; «Не знаю» принимается, решение пишется в журнал.
3. Спека с кнопками «Согласен» / «Поправить»; записывается только по кнопке.
4. Нарезка на задачи с картой покрытия; незакрытый критерий показывается отдельно с вопросом «осознанно ли?».
5. Смета и пакет «пройти самому» файлом.
6. Человек работает у себя и приносит результат (приём результата и «Сработало» ещё не построены, срез 12).

**6. Обычный разговор.** Агент отвечает коротко, по делу; выбор предлагает кнопками; вне рамок возвращает к делу.

## Что доступно на каждом этапе

| Этап | Доступно |
|---|---|
| Новый | Тест на входе, каталог навыков (смотреть и запускать), разговор с агентом |
| Анкета заполнена | Карточка, «Верно» / «Поправить» |
| Паспорт создан | Главная с тремя навыками, первый результат, запуск любого навыка |
| Навык идёт | Допрос → спека → задачи → пакет |
| Владелец | `/admin`, `/members`, `/skill_upload` (загрузка и публикация навыков) |

## Что нашлось при живой проверке 28.10

- Голосовая кнопка в Mini App видна только при заданных ключе и `QWEN_ASR_MODEL`; до входа в Mini App человек её увидеть не мог (вход не работал из-за кнопки на клавиатуре).
- Кнопки выбора появляются, когда агент сам решает задать вопрос; нет гарантированной точки входа с кнопками. Предложение: главное меню под приветствием («Рассказать о себе», «Мои навыки», «Открыть приложение»).
- Старая версия правил агента просила печатать ответ и обещала то, чего агент не умеет. Исправлено в конституции.
