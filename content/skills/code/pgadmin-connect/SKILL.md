## Назначение

Подключение pgAdmin к локальной базе: методика из материалов студии (урок 02), превращённая в навык. Результат: пошаговая инструкция подключения с реальными значениями из `.env`.
Навык работает в одну фазу (`runs_via: direct`): агент проводит методику по тексту ниже, а при
необходимости оборачивается в полный конвейер `dev-skills` внутри более крупного навыка.

## Когда включать

- хочу посмотреть содержимое базы глазами
- строка не появилась, нужно проверить

```text
### Подключение pgAdmin
Объясни мне, как подключить через pgAdmin базу данных, которую ты развернул локально для этого проекта. Дай мне пошаговую инструкцию с реальными данными, которые я должен ввести — возьми их из `.env` проекта.
```

## Критерии приёмки

- **К1.** Инструкция использует реальные значения пользователя, пароля, хоста, порта и имени базы из `.env`.
- **К2.** Шаги: Add New Server, General, Connection, сохранение.
- **К3.** В pgAdmin видны схемы, таблицы и строки пользователя.
- **К4.** Пароль pgAdmin (master password) объяснён как отдельный от пароля базы.

## Отказы и границы

- В чат пароль базы целиком не печатается: пользователь берёт его из своего `.env` на своей машине, агент показывает имена полей и значения без пароля.
- Не обещает человеку заработок и не выдаёт гипотезу за факт.
- Факты о рынке, ценах и правилах берёт только из `run_research` со ссылкой и датой.
