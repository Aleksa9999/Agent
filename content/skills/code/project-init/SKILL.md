## Назначение

Инициализация проекта: методика из материалов студии (урок 02), превращённая в навык. Результат: каркас проекта с базовой структурой каталогов.
Навык работает в одну фазу (`runs_via: direct`): агент проводит методику по тексту ниже, а при
необходимости оборачивается в полный конвейер `dev-skills` внутри более крупного навыка.

## Когда включать

- создать каркас проекта
- после stack.md
- нужно, чтобы проект запустился локально

## Адаптация под паспорт

| Переменная | Что меняет |
|---|---|
| `{project_name}` | имя папки и пакета |
| `{platform}` | команда инициализации по стеку |

Адаптация меняет формулировки, примеры и порядок вопросов. Правила методики и критерии приёмки не ослабляются.

## Допрос

Вопросы и порядок заданы методикой ниже. Общие правила студии для всех вопросов: пачками не больше пяти,
у каждого вопроса пронумерованные варианты или рекомендация, ответы, уже данные в паспорте или `_docs`, не
переспрашиваются, размытый ответ переспрашивается один раз с примерами.

## Конвейер

Одна фаза: провести методику строго по тексту. Текст методики ниже взят из материалов урока без изменений.
Если методика требует файла в `_docs/`, он создаётся только после подтверждения человека.

### Методика (текст урока)

```text
### Инициализация проекта
Требуется выполнить первоначальную инициализацию проекта. Прочитай файл _docs/stack.md и создай базовый каркас проект с нуля. На данном этапе не нужно устанавливать второстепенные зависимости, настраивать базу данных и так далее.
Требуется сделать так, чтобы проект просто локально запустился и внутри него создалась базовая структура каталогов.
Название проекта — [НАЗВАНИЕ].
Используй последние актуальные версии всех зависимостей. Выполни инициализацию проекта по последним стандартам.
Если на машине не установлены какие-то необходимые инструменты, сделай это. После создания проекта дай инструкции по его запуску.
```

## Коробка ИИ

| Уровень | Роли моделей |
|---|---|
| Эконом | `code` |
| Стандарт | `code`, `reasoning` |
| Премиум | `code`, `reasoning`, `vision` для скриншотов |

Цены считаются из `model_catalog`. Методика не требует дорогих генераций: уровни различаются глубиной проверки и поиска.

## Критерии приёмки

- **К1.** Проект создан по последним стандартам стека без второстепенных зависимостей.
- **К2.** Проект запускается локально и открывается на `localhost`.
- **К3.** Структура каталогов создана.
- **К4.** Выдана инструкция запуска.

## Отказы и границы

- Не настраивает базу и не ставит второстепенные зависимости на этом шаге.
- Не создаёт проект в домашней папке: только в отдельной папке проекта.
- Не обещает человеку заработок и не выдаёт гипотезу за факт.
- Факты о рынке, ценах и правилах берёт только из `run_research` со ссылкой и датой.

## Доказательство «Сработало»

Скриншот или лог запущенного проекта на localhost; папка проекта с `package.json` (или аналогом).
