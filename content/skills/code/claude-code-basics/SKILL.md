## Назначение

Научить человека, который выбрал дорогу «пройти самому», работать в Claude Code: чем он отличается от
чата, как устроены папка проекта, сессии, лимиты и контекст, зачем `CLAUDE.md` и `_docs`. Навык даёт
минимум для самостоятельной работы по остальным навыкам ветки «Код».

## Когда включать

- Человек выбрал «пройти самому» в навыке сайта, приложения или автоматизации.
- Человек просит объяснить, что делает агент, чтобы повторить это сам.

Не включать: человеку нужен результат, а не обучение. Тогда навык выполняет агент платформы.

## Допрос

1. **Система и редактор.** macOS или Windows, есть ли VS Code или Cursor. ➡️ Установка в терминале (Warp) плюс расширение редактора.
2. **Есть ли аккаунт и установленный Claude Code.** ➡️ Аккаунт оформляет сам человек по правилам провайдера; агент помогает только с установкой и настройкой.
3. **Что делаем первым.** Практики ниже. ➡️ Начать с языка в конфиге и рабочей папки.

## Конвейер

Одна фаза: провести человека по блокам ниже, после каждого блока проверка результата.

### Что такое Claude Code

Агент в терминале: читает и правит файлы, ищет в сети, выполняет команды на компьютере. Рабочий цикл: анализ → план → реализация.
В чате документы переносятся в окно вручную; в Claude Code открывается папка, даётся задача словами, агент сам читает файлы,
считает и пишет код. Установка: официальная инструкция на https://code.claude.com/docs/en/setup (команда из документации, затем запуск командой `claude`).
Claude Desktop содержит режимы Chat, Cowork, Design и Code; для работы с файлами и кодом нужен Code.

### Установка и окружение

- Терминал: Warp (вертикальная раскладка удобна для работы с агентом).
- Расширение в редакторе: VS Code или Cursor.
- Windows: при ошибке `claude` не найден добавляется путь в переменные среды (Дополнительно → переменные среды → path → изменить), затем перезапуск терминала.
- Голос вместо печати: WisprFlow (платный, точнее) или Handy (бесплатный), либо встроенная команда `/voice` в подписке.
- Конфигурация живёт в `~/.claude/settings.json`; параметр `language` задаёт язык ответов по умолчанию.

### Рабочая папка

Claude работает в той папке, из которой запущен: кладёт туда код, файл памяти, базу знаний, скиллы.
Порядок: создать папку → `cd` в неё → `claude` → доверить файлам. Имена латиницей, без пробелов.
Один проект — одна папка (например, `mycrm`, `content`, `sales-outreach`). Запускать в домашней папке нельзя.

### Сессии, лимиты и контекст

- Сессия — это диалог с агентом; `/clear` начинает чистую сессию, `/rename` называет, `/resume` возвращает, `claude -c` открывает последнюю.
- Лимиты бывают сессионные и недельные; `/usage` показывает остаток и время сброса.
- У модели нет памяти: на каждый запрос отправляется весь разговор. Чем длиннее сессия, тем быстрее расходуется лимит и тем хуже качество («context rot»). Правило: новая задача — новая сессия (`/clear`). Заполненность контекста показывает `/context` и строка статуса.
- `CLAUDE.md` лежит в корне проекта и даёт постоянную память: повторяющиеся инструкции хранятся там и подгружаются в каждую сессию.
- База знаний проекта: папка `_docs` с `project.md`, `competitors.md`, `stack.md`, `design-system.md`; `CLAUDE.md` ссылается на них и отвечает, какой документ про что.

### Команды и режимы

Встроенные команды: `/help`, `/model`, `/init`, `/exit`, `/terminal-setup`.
Режимы: дефолтный (спрашивает разрешение перед правкой), Plan mode (планирование), Auto accept edits (автоматическое редактирование),
Auto mode (частичный автопилот), Dangerously skip permissions (полный автопилот).

**Предупреждение студии.** Полный автопилот включают только в отдельной папке проекта, после коммита и без секретов в папке. Агент без запросов разрешений может удалять и менять файлы.

### Практика

Пять заданий из материалов урока, текст каждого без изменений:

#### Дашборд по договорам
```text
В папке deals лежат договоры на размещение рекламы в Telegram-каналах — 30 PDF-файлов.
Прочитай их все и собери таблицу сделок: заказчик, ИНН, номер договора, дата договора,
канал размещения, дата публикации, стоимость закупки площадки, стоимость услуг
исполнителя, итоговая сумма, статус оплаты.
На основе этих данных собери дашборд в одном файле dashboard.html — весь код внутри
файла, без внешних библиотек:
- общая выручка, выручка по месяцам и за последние 30 дней;
- сколько уже оплачено и сколько висит в ожидании оплаты;
- клиенты: количество сделок, сумма, дата последней сделки и сколько дней с неё прошло;
- каналы: количество размещений, закупка, выручка и маржа по каждому;
- средний чек и общая маржинальность.
За «сегодня» бери текущую дату.
Сделай тёмную тему, ключевые цифры вынеси карточками наверх, таблицы — под ними.
Когда закончишь, открой файл в браузере.
```

#### Русский язык в конфиге
```text
в пользовательском конфиге с настройками клод код замени значение для параметра language на русский язык, чтобы клод по дефолту отвечал на нем
```

#### Конспект-презентация по уроку
```text
Собери презентацию по уроку из файла transcripts/krugi-eylera.md.
Прочитай транскрибацию целиком и вытащи из неё то, что ученик должен унести
с урока: разобранные темы, формулы, задачи вместе с решением, ошибки, на
которые я обращал внимание, и домашнее задание.
Когда закончишь — открой презентацию в браузере.
```

#### Правило в CLAUDE.md
```text
Добавь в CLAUDE.md правило: в презентации по уроку должно быть не больше семи слайдов — только самое важное.
```

#### Алиас claude-dsp
```text
Создай алиас “claude-dsp”, который будет запускать claude с флагом --dangerously-skip-permissions.
```

Дашборд и презентация требуют исходных файлов (папка `deals` и транскрипт урока); если их нет, агент
готовит тестовые: 30 сгенерированных договоров с вымышленными данными и короткий текст урока.

## Критерии приёмки

- **К1.** `claude` запускается в папке проекта, `claude --version` выводит версию.
- **К2.** Папка проекта названа латиницей без пробелов, Claude Code запущен именно из неё, а не из домашней.
- **К3.** В `~/.claude/settings.json` указан язык ответов, и Claude отвечает на нём по умолчанию.
- **К4.** В проекте есть `CLAUDE.md` с хотя бы одним правилом, и в новой сессии оно действует (проверено примером).
- **К5.** Человек может объяснить своими словами, почему для новой задачи нужен `/clear` и что показывает `/usage`.
- **К6.** Практика «Дашборд по договорам» выдаёт таблицу сделок и файл `dashboard.html`, открывающийся в браузере; цифры сверены с исходными данными выборочно.
- **К7.** Практика «Правило в CLAUDE.md» подтверждена: после `/clear` тот же промпт даёт результат, соответствующий правилу.
- **К8.** Алиас запуска создан, и человек знает, когда его использовать нельзя.

## Отказы и границы

- Аккаунт Claude, оплата и доступ оформляются человеком самостоятельно и по правилам провайдера. Навык не даёт инструкций по обходу региональных ограничений провайдера, виртуальным картам и подмене адреса для получения доступа.
- Не просит передавать пароли и ключи в чат.
- Не включает полный автопилот в папках с секретами и важными данными без коммита.

## Доказательство «Сработало»

Скриншот терминала с `claude --version` и запущенной сессией в папке проекта, `CLAUDE.md` с правилом и результат одной практики (файл `dashboard.html` или презентация).
