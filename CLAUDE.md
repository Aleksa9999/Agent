# Googlagent — правила проекта

Telegram-бот и Mini App: персональный ИИ-агент студии SuperAi Studio. Руководитель студии — Арсен. Главная идея: каждый реальный шаг человека
превращается в проверенный навык агента; уроки заменены навыками.

## Документы

- `_docs/decisions.md` — решения Арсена, главный источник правды; читать первым
- `_docs/project.md` — зачем продукт, для кого, принципы, роли
- `_docs/skills-model.md` — навыки, уровни, зачёт в счётчик, две дороги
- `_docs/placement-test.md` — тест на входе и подбор трёх навыков
- `_docs/stack.md` — что в стеке; читать перед вводом новой зависимости
- `_docs/changes-vs-tz.md` — как изменились задачи T00–T41 после решений
- `content/skills/_FORMAT.md`, `_PIPELINE.md`, `INDEX.md` — формат, конвейер и список навыков
- `content/methods/dev-skills/` — конвейер разработки (`grill-me`, `to-spec`, `to-tasks`, `implement`, `code-review`, `security-review`, `handoff`); не править
- ТЗ и концепция (`Googlagent SuperAi Studio`, `Googlagent · 1000aiskill`) лежат у Арсена; где они расходятся с `_docs/decisions.md`, действует `decisions.md`

## Правила

- Язык кода и идентификаторов английский, тексты для людей русские в файлах i18n; ничего не вписывать в код строкой.
- Тесты и проверки: `make check` (линтер, все тесты, валидатор навыков). Отдельно: `python3 -m pytest`, `python3 -I tools/validate_skills.py`. Без Docker стек поднимается командой `make native-up`.
- Раскладка кода: `app/` (бот, агент, база, `app/skills` библиотека навыков), `skillkit/` (общий валидатор и разбор навыков: его же зовёт `/skill_upload`; русские слова формата навыка живут здесь, а не в `app/`), `config/tenants/*.yaml` (бренды), `locales/*.yaml` (все тексты для людей), `deploy/` (запуск, бэкап, откат), `tests/`.
- Секреты только в `.env` на сервере (`chmod 600`), раздельно для test и prod. Не печатать их в вывод, логи, коммиты, отчёты и чат. Архивы с паролями не открывать.
- Переменные окружения: `QWEN_API_KEY`, `QWEN_BASE_URL`, `QWEN_MODEL`, `QWEN_FAST_MODEL`, `DASHSCOPE_API_KEY`, `TG_BOT_TOKEN`, `TG_TEST_BOT_TOKEN`, `OWNER_TG_ID`, `GROUP_CHAT_ID`, `WEBAPP_URL`, `DATABASE_URL`, `REDIS_URL`, `FERNET_KEY`, `GITHUB_TOKEN`, `OPENAI_API_KEY`, `ELEVENLABS_API_KEY`.
- ID моделей и цены не хардкодить: настройки и `model_catalog`. Цены в навыках только в виде ролей моделей.
- Деньги: перед платным вызовом `estimate` и проверка баланса; порог подтверждения участником 50 кредитов, одобрение Арсена 1000 (настраиваются).
- Личное (деньги, контакты, возраст) в общую группу не публикуется; публичное только поле `public` в решениях.
- Факты о мире (цены, законы, экзамены) в тексты навыков не вписываются, их приносит `run_research` со ссылкой и датой.
- Любая работа с боевым токеном, боевой группой, тарифом сервера и деньгами — только с одобрения Арсена. Тестируем на тестовом боте и тестовой группе.
- Коммит: `<область>: <короткое описание в нижнем регистре>` по-английски, в теле трейлер `Spec: <slug>/<NN>` (`/review` для правок ревью).
- Навыки меняются новой версией (`v1` → `v2`), старая версия остаётся. Правка `SKILL.md` или `test.yaml` обязана проходить валидатор.
- Навык засчитывается в счётчик только после автотеста, реального запуска и кнопки «Сработало»; XP начисляется только по событию-доказательству.

## Конвейер разработки

`/grill-me` → `/to-spec` → `/to-tasks` → `/implement` → `/code-review` (внутри `/security-review`). Мелкие правки идут мимо конвейера.
Новая фича или волна начинается со спеки в `_specs/<slug>/`.
